# Earth texture attribution

Source: WebGL Earth example textures, https://github.com/turban/webgl-earth/tree/master/images

- `earth-day.jpg`: derived from `2_no_clouds_4k.jpg` (NASA Blue Marble Earth imagery).
- `earth-clouds.jpg`: alpha channel derived from `fair_clouds_4k.png`.

Both textures were resized to 2048 × 1024 and JPEG-compressed for local delivery. No texture CDN or external request is needed at runtime.
NASA imagery guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/
