# 浮生 · Life in bloom

一个收藏人生片段、推动下一步行动的私人小宇宙。深空黑灰与深蓝底色、左下角纯 CSS 装饰地球、三个柔和浮动的气泡，支持手机和桌面。

## 本地运行

需要 Node.js 20.19+ 或 22.12+（当前环境已验证 Node.js 24）。

```sh
npm ci --cache /tmp/fusheng-npm-cache
npm run dev
```

生产构建：`npm run build`。查看构建：`npm run preview`。

## 功能

- 经历与瞬间、关系与连接、探索与成长三个板块；点击气泡筛选记录。
- 创建、阅读、编辑和删除记录；日期、标题和正文。
- 可选的下一小步、完成状态和首页行动提醒。
- 标题和正文搜索。
- 浏览器 localStorage 自动保存；JSON 导出和导入。导入按记录 ID 去重，保留当前已有记录。
- 响应式布局、键盘可操作弹窗、减少动态效果支持。

## 数据说明

没有账户、后端或跨设备同步。记录保存在当前浏览器、当前站点的本地存储中；切换设备、浏览器、域名或端口不会共享数据。清除站点数据会删除记录，请定期导出备份。无痕模式的数据可能在关闭窗口后丢失。

字体可选使用 Google Fonts，加载失败时使用系统字体，不影响功能。导出的 JSON 是未加密文件，请自行妥善保管。

## 验证

生产构建通过；使用 Chromium 自动化验证了创建、刷新持久化、编辑、删除、行动完成、板块筛选、搜索、导出/导入去重、390px 手机布局和编辑。测试使用独立浏览器上下文，不会向用户浏览器写入示例数据。
